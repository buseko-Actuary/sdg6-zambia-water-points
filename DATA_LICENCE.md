# Data licence and attribution

The file `data/raw/wpdx_water_points_zmb.csv` is **not** covered by this
repository's MIT licence. It is third-party data, redistributed here unchanged
so that the analysis is reproducible offline.

## Source

**Water Point Data Exchange (WPdx)**, *Water Point Data Exchange (ZMB)*.
Accessed 3 September 2026 via the UN OCHA Humanitarian Data Exchange.

- Dataset page: <https://data.humdata.org/dataset/wpdx_zmb>
- Publisher: <https://www.waterpointdata.org/>
- Coverage: 1 January 2012 to 7 December 2025
- Resource used: `wpdx_water_points_zmb` (`wpdx_enhanced.csv`), 6,643 records

Village Water, Village Water Zambia, Living Water International, UNHCR,
